What Can You Bulk Import?

  • Students: Names, admission numbers, classes, gender, DOB, parent names, parent phone, parent email
  • Staff: Names, staff IDs, positions, qualifications, salary, phone, email

first_name last_name admission_no class_name gender dob parent_name parent_phone parent_email address

How to Bulk Import in SkulCBT

1

Download CSV Template

Go to Students Import or Staff Import page. Click Download Template. The template auto-generates with your school's class names.

2

Fill Your Data

Open the CSV in Excel or Google Sheets. Fill student or staff data in the correct columns. Save as CSV.

3

Upload CSV

Go back to the import page. Click Upload CSV and select your file. The system validates and imports all data.

4

Review & Confirm

Review the imported data. Confirm and save. All students or staff are now in your system. Ready to use.

Tips for Successful CSV Import

  • Use the template: Always download the template first. It has the correct column headers and formats.
  • Check class names: Class names must match exactly what's in your system. The template auto-populates them.
  • Valid dates: Use YYYY-MM-DD format for dates (e.g., 2008-05-15).
  • Valid phone numbers: Use 11-digit Nigerian phone numbers (e.g., 08012345678).
  • No empty required fields: First name, last name, and class are required for students. First name, last name, and position are required for staff.
  • Save as CSV: Save your file as .csv format, not .xlsx.

FAQ — School Admins Ask

What file format is required for bulk import?

SkulCBT supports CSV (Comma Separated Values) files for bulk import. You can create CSV files using Excel, Google Sheets, or any spreadsheet software.

Does the template auto-generate with my class names?

Yes. When you download the student import template, it automatically includes all your school's classes in the class_name column. You just fill in student details.

Can I import staff data from Excel?

Yes. You can import staff from CSV or Excel files. The system validates the data before importing to ensure everything is correct.

What happens if there's an error in my CSV?

The system validates each row. If there are errors, you'll see a report showing which rows have issues. Fix them and upload again.
